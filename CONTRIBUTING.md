# Contributing

Read README.md, docs/AI_AND_DEVELOPMENT.md and AGENTS.md. Open an issue describing the change, or send a focused pull request with reproduction steps and relevant test results.

- Keep native game assets read-only and out of the repository.
- Never commit personal blueprints, credentials, local configuration or captured user data.
- Preserve unknown controller storage, IDs and saved poses.
- Use portable paths and dependency versions from the lockfile.
- Keep limitations explicit. Native spawning, driving and flight cannot be certified by an independent solver.
- Add meaningful regression coverage for behavioral fixes; identify any required local fixtures.
- Do not add paid AI integrations, API-key requirements or browser-token automation to the existing workflow.

Contributions to this project are provided under its MIT license. Third-party additions must retain their license and attribution.
